# dtos

Data Transfer Objects de entrada/saída dos use cases — o formato que `presentation` envia para `application` e recebe de volta, desacoplado do formato HTTP bruto e do formato de persistência.

Vazio nesta sprint: o único use case (`GetSystemHealthUseCase`) não precisa de input e devolve um tipo já compartilhado (`HealthCheckResponse` em `@rip/shared-types`).
